# amm_init_tip's Prover.toml has old_c = 0, and its new_c (the first pool
# commitment, POOL) is the old_c of every swap case on the live pool. Each
# swap case outputs [ok, partial_note, code, amount_out], the trader's
# partial note echoed for apply's completion; a rejected case re-commits the
# state unchanged (new_c = old_c), the trade makes a new commitment. drain
# and bad-reserve start from pools of their own. amm_swap_tip_next, the
# upgraded swap, trades its Prover case exactly as amm_swap_tip does and
# refuses its small case (amount_in 50, below MIN_TRADE) with code 10.
#
# amm_swap_tip_shared's outputs are pss_core Private, so its rows check
# them by value: every case reads POOL (0x216c...) and writes under the
# fresh blinding 444 whatever the outcome, the trade the non-secret-shared
# trade's new commitment (0x0390...), every failure the pool kept
# (0x1c13...), never POOL; its note hash completes the trader's partial
# note with [code, amount_out, request_id] at OUTCOME_SLOT 1 (the trade's
# [0, 33450, ...]), and amount_out is 0 on every failure. The mismatch has
# the trade's request id and attempt (the same C), with code 9 in its
# note and ciphertext.
